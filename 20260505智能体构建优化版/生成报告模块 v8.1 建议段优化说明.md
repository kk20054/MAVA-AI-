# 生成报告模块 v8.1 建议段优化说明

## 问题现象

截图中的“下一步建议”容易出现“建议动作（依据：某某指标）”的写法。这种格式虽然能说明数据来源，但不像正常经营分析报告：它缺少问题识别、影响判断、具体动作和跟踪闭环，读起来更像模型把素材拼接成清单。

## v8.1 调整思路

本版从三层处理：

1. 上游预处理脚本
   - 文件：`生成报告模块—数据预处理 v8.1.py`
   - 将 `suggestion_candidates` 从一句话建议改成“议题、观察、判断、动作、跟踪”的结构化素材。
   - 模型不再只能拿到“建议 + 依据”，而是拿到完整经营建议链条。

2. 报告分析师提示词
   - 文件：`生成报告模块—报告分析师 v8.1.txt`
   - 明确要求“下一步建议”每条写成 3-4 句话的自然段落。
   - 明确禁止“依据：”“理由：”“数据依据：”以及括号依据写法。
   - 要求建议段按“数据观察 -> 经营判断 -> 具体动作 -> 跟踪闭环”展开。

3. 末端内容规范脚本
   - 文件：`生成报告模块—process_AI_content v8.1.py`
   - 如果模型仍输出“（依据：xxx）”，脚本会把括号依据改写成自然句，减少 HTML 报告里的机械表达。

## 建议替换方式

保留 v8 的意图守卫、路由、参数抽取和接口参数组装：

- `生成报告模块 — 意图守卫提示词 v8.txt`
- `生成报告模块 — 路由脚本 v8.py`
- `生成报告模块—参数抽取提示词 v8.txt`
- `生成报告模块—接口参数组装脚本 v8.py`

替换以下 3 个文件：

- `生成报告模块—数据预处理 v8.1.py`
- `生成报告模块—报告分析师 v8.1.txt`
- `生成报告模块—process_AI_content v8.1.py`

## 建议段目标样式

不推荐：

`-优化低息存款结构（依据：低息存款占比3.00%）`

推荐：

`-优化低息存款结构：低息存款占客户存款3.00%，反映低成本资金沉淀仍有明显提升空间。建议围绕结算沉淀、代发代扣和重点客群维护提升活期及储蓄存款留存，并对高成本定期存款做好到期分层管理。后续可持续跟踪低息存款占比、重点客户余额变动和定期迁徙情况。`
