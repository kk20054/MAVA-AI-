# MAVA 问数模块 v9 优化版工作流

## 1. 推荐链路

用户问题
→ 意图守卫（只判断是否属于本模块，默认放行）
→ 参数抽取 LLM（沿用现有指标、日期、OIC、层级抽取）
→ `process_intent2_output v9.0.py`（语义侧写、参数补全、日期映射、数据量控制）
→ 指标接口
→ `data_slicing v9.0.py`（银行口径预计算、异动/贡献/风险/下钻诊断素材、Markdown 表格）
→ `问数回答专家 v9.0.ini`（自然语言经营分析）
→ 最终回答 + 推荐追问

## 2. v9 相比 0503 v8.1 的核心变化

1. 增加 `_query_profile`：把“经营概况、异动归因、贡献结构、趋势、风险预警、下钻明细”等用户真实意图结构化传给后续脚本。
2. 参数空缺时自动补齐经营分析默认口径：经营概况默认覆盖 Revenue、Assets、Liabilities，层级默认 L1/L2；需要下钻时补 L3。
3. 数据切片增加“经营诊断素材”：将异动识别、贡献结构、风险关注、下钻方向放入提示词，让模型输出更像日常经营分析，而不是只复述表格。
4. 修正 v8.1 中 highlight 方向可能丢失的问题：下降类异动会被识别为下降或风险关注，不会统一写成增长。
5. 回答专家提示词改为“总括-分端-异动-贡献-风险-表格-注释”的管理会计表达框架。

## 3. 落地建议

短期可直接替换试跑：
- `process_intent2_output v9.0.py`
- `data_slicing v9.0.py`
- `问数回答专家 v9.0.ini`
- 两个 v8 意图守卫提示词
- `生成报告模块 — 路由脚本 v8.py`

中期建议在接口层补齐：
- 客户维：客户数、AUM、支薪户、新增/流失、客户分层。
- 产品维：存款/贷款/中收产品结构、到期续作、利率敏感项。
- 部门维：团队/分行/条线排名、贡献、目标完成率。
- 时间维：月度序列至少 6-12 期，便于做趋势、季节性和连续异动识别。

长期建议升级为“指标语义层”：
- 指标注册表维护口径、单位、正负向、所属端、默认比较方式、可下钻维度。
- 每个指标绑定经营解释模板和异常阈值。
- 输出分为标准 JSON 分析包和自然语言展示，降低对模型自由发挥的依赖。
