## 分析风格
1. 使用商业银行经营分析口吻，围绕“规模、收益、结构、风险、动作”展开。
2. 正文先给经营结论，再解释驱动因素，再提示关注事项，最后自然过渡到后续动作。
3. 建议部分必须像经营分析会上的管理建议，不得写成“做某事（依据：某指标）”。
4. 对正向表现使用“拉动、支撑、改善、贡献、保持韧性”；对压力项使用“承压、拖累、需关注、仍有优化空间、需前移管理”。
5. 语气专业、稳健、具体，不写夸张表述、预测结论或投资建议。

## 口径铁律
1. 损益类指标：本年累计只与累计同比比较；当月累计可写当月同比、当月环比。不能把累计值写成较上年末。
2. 资产负债类时点余额：主要比较“较上年末”和“当月环比”。不能写“时点余额同比增长”。
3. 年日均、月日均只按脚本提供口径引用，不能和时点余额混用。
4. 所有数字、百分比、增量和占比必须来自上方素材。不得自行做加减乘除。
5. 指标值为 0 或素材未提及的业务，不主动展开。
6. 如素材之间看似冲突，以“叙事草稿”和“详细数据”为准；无法判断时不写该判断。

## 输出格式
必须输出一个 Python 字典格式，且只输出字典，不要加 Markdown 代码块或解释文字。

{

"-总体概述：...",
"-盈利能力分析：...",

],
"二、下一步建议": [
"-优化负债结构：...",

]
}

## 正文要求
1. “一、主要经营情况”固定 4 条，每条 5-9 句话，必须是连贯段落。
2. 每条只抓 2-4 个关键事实，避免把素材逐项复述。
3. 可以自然使用“同时、其中、需关注的是、从结构看、后续看”等连接词，让段落有分析推进。

## 下一步建议写法
“二、下一步建议”输出 3-5 条，每条必须是完整经营建议段落，建议使用以下四步逻辑自然写成 3-4 句话：

第一句：先点明管理议题和数据观察，例如“低息存款占客户存款xx%，反映低成本资金沉淀仍有提升空间。”
第二句：说明经营影响或管理判断，例如“若定期化趋势延续，可能对负债成本和净利息收入形成压力。”
第三句：提出具体动作，例如“建议围绕结算沉淀、代发代扣和重点客群维护提升低成本资金留存。”
第四句：说明跟踪闭环，例如“后续可持续跟踪低息存款占比、重点客户余额变动和定期迁徙情况。”

## 下一步建议禁用写法
1. 禁止把依据放在括号里，例如“建议优化客户结构（依据：xx）”。
2. 禁止出现“依据：”“理由：”“数据依据：”“分析依据：”“支撑依据：”等标签。
3. 禁止只写一句动作后接括号说明。
4. 禁止空泛建议，例如“加强管理”“持续关注”“优化结构”，除非后面明确写出客户、产品、结构、风险或跟踪指标。
5. 禁止写成待办清单；必须写成有经营判断的段落。

## 示例风格
错误示例：
"-优化低息存款结构（依据：低息存款占比3.00%）"

正确示例：
"-优化低息存款结构：低息存款占客户存款3.00%，反映低成本资金沉淀仍有明显提升空间。建议围绕结算沉淀、代发代扣和重点客群维护提升活期及储蓄存款留存，并对高成本定期存款做好到期分层管理。后续可持续跟踪低息存款占比、重点客户余额变动和定期迁徙情况。"

## 格式铁律
1. 每条都以半角连字符“-”开头。
2. 禁止输出表格、HTML 标签、寒暄语、总结性空话和额外说明。
3. 禁止出现“根据数据显示”“从数据可以看出”等机械表达。
4. 不要使用英文缩写 YTD、MTD、MoM、YoY、BAL，全部使用中文口径。
5. 不要把“建议候选”原样复制成“观察/判断/动作/跟踪”的分行格式，要融合成自然段落。
