## 模块总览

### 1. 知识问答模块

当前路径：

```text
MAVA AI智能体/最新版本/知识问答模块/
```

当前版本：`v10.2`

职责：处理制度口径、业务知识、市场背景、公开信息与知识库检索类问题。该模块重点解决“先检索、再筛选、再融合、最后基于证据生成答案”的链路。

当前推荐流程：

1. 用户问题进入 `prompts/01_查询解析与参数化提示词 v10.2.txt`
2. `scripts/02_查询改写与路由 v10.2.py` 做查询改写、路由、关键词和兼容字段补齐
3. `docs/03_判断is_intro节点说明.txt` 判断是否走引言或兜底路径
4. 调用 BKS 知识库检索和 WebSearch 联网检索
5. `scripts/06-1_联网检索多信号筛选 v10.2.py` 处理联网结果
6. `scripts/06-2_BKS知识库多信号筛选 v10.2.py` 处理知识库结果
7. `scripts/06-3_检索结果融合与预算控制 v10.2.py` 做去重、排序、上下文预算控制
8. `scripts/07_合成生成与引言兜底 v10.2.py` 基于证据组织答案
9. `prompts/08_业务支持专家提示词 v10.2.txt` 约束业务表达风格
10. `scripts/09_type999_res_output.py` 处理兜底和异常类型输出

v10.2 的核心变化：

- 将 01 查询解析提示词轻量化，减少前置模型节点耗时
- 继续兼容 v10.1 的字段补齐逻辑
- 保留多信号筛选，避免只依赖单一 `relevance` 分数
- 对 HIBOR、LPR、SOFR、汇率等市场时效类问题保护实体、日期、数值和期限字段

### 2. 数据查询模块

当前路径：

```text
MAVA AI智能体/最新版本/数据查询模块/
```

当前版本：`v9`

职责：处理经营数据查询、指标口径查询、客户/产品/机构维度下钻、经营诊断素材组织和自然语言经营分析输出。该模块对应旧目录中的“问数查询模块”。

当前推荐流程：

1. 用户问题先经过意图守卫和参数抽取
2. `scripts/process_intent2_output v9.1.py` 做语义改写、参数补全、日期映射和查询画像整理
3. 指标接口返回结构化经营数据
4. `scripts/data_slicing v9.2.py` 做银行口径预计算、异常识别、贡献结构、风险关注和 Markdown 表格组织
5. `prompts/问数回答专家 v9.0.ini` 负责最终经营分析表达

v9 的核心变化：

- 增加 `_query_profile`，把经营概况、异动归因、贡献结构、趋势、风险预警、下钻明细等意图结构化
- 参数缺失时自动补齐经营分析默认口径
- 数据切片新增经营诊断素材包，让模型输出更接近日常经营分析
- 修复 v8.1 中下降类异动容易被写成增长方向的问题

### 3. 生成报告模块

当前路径：

```text
MAVA AI智能体/最新版本/生成报告模块/
```

当前版本：`v8.1`

职责：处理报告生成链路，包括报告对象识别、指标和维度组织、结构化素材预处理、报告分析师生成和最终内容规范。

当前推荐流程：

1. 沿用 v8 的意图守卫和路由能力识别生成报告请求
2. 参数抽取提示词识别报告对象、指标、日期和维度
3. 接口参数组装脚本生成取数参数
4. `scripts/生成报告模块—数据预处理 v8.1.py` 组织结构化分析素材
5. `prompts/生成报告模块—报告分析师 v8.1.txt` 生成报告主体
6. `scripts/生成报告模块—process_AI_content v8.1.py` 做末端内容规范，尤其优化“下一步建议”段落

v8.1 的核心变化：

- 将建议段从“建议 + 依据”的机械拼接，改成“数据观察、经营判断、具体动作、跟踪闭环”
- 上游预处理脚本输出结构化建议素材
- 报告分析师提示词要求自然段表达，避免括号式依据堆叠
- 末端脚本对模型输出中的机械依据表达做二次规范

## 文件组织约定

每个模块内按以下结构管理：

```text
docs/       # 工作流、优化说明、接入说明
prompts/    # 提示词、专家角色、ini 配置
scripts/    # Python 脚本
release/    # 面向发布或复制使用的文本稿
```

维护规则：

1. Python 脚本放入 `scripts/`
2. 提示词、专家角色和 `.ini` 配置放入 `prompts/`
3. 工作流、接入说明和优化说明放入 `docs/`
4. 已整理为交付稿的纯文本放入 `release/`
5. HTML demo 放入 `examples/`
6. 办公文档、截图、压缩包、缓存和本地运行环境不提交
