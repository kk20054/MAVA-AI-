# MAVA AI 智能体

本仓库用于管理 MAVA AI 智能体相关的脚本、提示词、工作流说明和 HTML demo。仓库已按版本和模块重新整理，重点对 Python 脚本与提示词进行版本控制，办公文档、压缩包、截图、浏览器缓存和本地临时文件不纳入 Git。

## 目录结构

```text
MAVA AI智能体/
  00-基础原型/                  # 0204 财会助手早期配置与映射表
  01-早期原型/                  # 0303 智能体搭建提示词
  v7/                           # 生成报告与问数查询的基础版本
  v8/                           # 生成报告模块 v8
  v8.1/                         # 生成报告模块 v8.1、问数查询 v8.1
  v9/                           # 问数查询模块 v9 最新主线
  v10/                          # 知识问答模块 v10
  v10.1/                        # 知识问答模块 v10.1 字段兼容修复
  v10.2/                        # 知识问答模块 v10.2 轻量化最新主线
  examples/                     # HTML demo 和看板联动示例
  docs/                         # 项目级调研与工作准则
参考示例/                       # 原“总行参考”，作为参考样例保留
```

各版本模块内一般按以下子目录组织：

```text
docs/       # 工作流、优化说明、接入说明
prompts/    # 提示词、专家角色、ini 配置
scripts/    # Python 脚本
release/    # 已整理为交付/复制使用的脚本或提示词文本稿
demo/       # HTML 示例
```

## 当前最新版本

### 知识问答模块：v10.2

位置：`MAVA AI智能体/v10.2/知识问答模块/`

v10.2 是当前知识问答主线版本，重点是降低查询解析阶段的模型耗时，同时保留 v10.1 的字段兼容能力。

推荐流程：

1. 用户问题进入 `01_查询解析与参数化提示词 v10.2.txt`
2. `02_查询改写与路由 v10.2.py` 补齐路由字段、检索词、任务画像和兼容字段
3. `03_判断is_intro节点说明.txt` 判断是否走引言/兜底路径
4. 进入 BKS 知识库检索与 WebSearch 检索
5. `06-1_联网检索多信号筛选 v10.2.py` 处理联网结果
6. `06-2_BKS知识库多信号筛选 v10.2.py` 处理知识库结果
7. `06-3_检索结果融合与预算控制 v10.2.py` 做去重、排序、预算控制
8. `07_合成生成与引言兜底 v10.2.py` 基于证据生成答案
9. `08_业务支持专家提示词 v10.2.txt` 约束业务表达
10. `09_type999_res_output.py` 输出兜底/异常类型结果

### 问数查询模块：v9

位置：`MAVA AI智能体/v9/问数查询模块/`

v9 是当前问数查询主线版本，围绕经营分析、指标口径、日期映射、数据切片和自然语言分析输出做了增强。

推荐流程：

1. 用户问题经过意图守卫和参数抽取
2. `process_intent2_output v9.1.py` 做语义改写、参数补全和日期映射
3. 指标接口返回结构化数据
4. `data_slicing v9.2.py` 做银行口径预计算、经营诊断素材组织和 Markdown 表格生成
5. `问数回答专家 v9.0.ini` 负责最终经营分析表达

### 生成报告模块：v8.1

位置：`MAVA AI智能体/v8.1/生成报告模块/`

v8.1 是当前生成报告模块的优化版本，重点改进建议段表达，把“建议 + 依据”的机械拼接改为“观察、判断、动作、跟踪”的经营分析段落。

推荐流程：

1. v8 意图守卫和路由脚本识别生成报告请求
2. 参数抽取提示词识别报告对象、指标、日期和维度
3. 接口参数组装脚本生成取数参数
4. `生成报告模块—数据预处理 v8.1.py` 组织结构化分析素材
5. `生成报告模块—报告分析师 v8.1.txt` 生成报告主体
6. `生成报告模块—process_AI_content v8.1.py` 做末端内容规范与建议段改写

## 版本维护约定

1. 新脚本优先放入对应版本的 `scripts/`。
2. 新提示词、专家角色和 `.ini` 配置放入 `prompts/`。
3. 面向复制发布的文本稿放入 `release/`。
4. 工作流、接入说明、优化说明放入 `docs/`。
5. 新版本不覆盖旧版本，按 `v10.3`、`v11` 等目录追加。
6. 办公文档、截图、压缩包、缓存和本地运行环境不提交。
